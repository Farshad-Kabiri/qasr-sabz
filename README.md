# مدیریت شارژ ساختمان

برنامهٔ فارسی و راست‌چین برای مدیریت واحدها، شارژ، پرداخت‌ها و هزینه‌ها با React، Vite و Supabase.

## نیازمندی و راه‌اندازی محلی
Node.js نسخهٔ ۱۸ یا جدیدتر و npm لازم است. ابتدا در Supabase یک پروژه بسازید یا پروژهٔ موجود را انتخاب کنید. از **Project Settings → API**، **Project URL** و یک کلید عمومی **anon/public** یا **publishable** بردارید. کلید `service_role` یا هر کلید secret را هرگز در مرورگر یا متغیر `VITE_*` قرار ندهید.

در ریشهٔ پروژه `.env.example` را به `.env` کپی و مقادیر نمونه را با مقادیر واقعی جایگزین کنید: `VITE_SUPABASE_URL` و یکی از `VITE_SUPABASE_ANON_KEY` یا `VITE_SUPABASE_PUBLISHABLE_KEY` (نام دوم را در صورت نیاز دستی اضافه کنید). کپی اختیاری در Windows PowerShell:

```powershell
Copy-Item .env.example .env
```

دستورهای اجرا:

```sh
npm install
npm run dev
```

پس از تغییر `.env`، Vite را متوقف و دوباره اجرا کنید. برای بررسی نسخهٔ انتشار: `npm run build`.

## پایگاه داده و نخستین استفاده
- **پایگاه تازه:** در Dashboard همان پروژه، **SQL Editor → New query** را باز کنید و کل `supabase-schema.sql` را اجرا کنید. برنامه را باز کنید، حساب بسازید/وارد شوید، ایمیل را در صورت فعال بودن تأیید ایمیل تأیید کنید، سپس فرم «ایجاد ساختمان» را به‌کار ببرید. واحد، هزینه، شارژ و پرداخت آزمایشی ثبت کنید و با جابه‌جایی ماه و بارگذاری دوباره، ذخیره و فیلتر تاریخ را بررسی کنید.
- **پایگاه موجود:** این فایل، migration عمومی برای schemaهای متفاوت نیست. `CREATE TABLE IF NOT EXISTS` ستون یا قید موجود را تغییر نمی‌دهد. ابتدا ساختار و داده‌های موجود را بررسی و migration هدفمند و پشتیبان‌گیری‌شده تهیه کنید؛ اسکریپت را کورکورانه اجرا نکنید. اجرای SQL باید در محیط خودتان تأیید شود.
- اگر SQL را اجرا نکرده‌اید، مجوزها یا تنظیم Auth درست نیست، خطای برنامه را بررسی کنید. بدون تنظیم Supabase برنامه به حالت نمایشی می‌رود؛ داده‌های نمایشی فقط در حافظهٔ همان نشست‌اند و با بارگذاری صفحه پاک می‌شوند.

## استقرار Vercel (اختیاری)
پروژه را از Git وارد Vercel کنید، Framework را **Vite**، Build Command را `npm run build` و Output Directory را `dist` قرار دهید. در **Project Settings → Environment Variables**، `VITE_SUPABASE_URL` و فقط یکی از کلیدهای عمومی `VITE_SUPABASE_ANON_KEY` یا `VITE_SUPABASE_PUBLISHABLE_KEY` را تنظیم و سپس redeploy کنید. مقادیر `VITE_*` در کد مرورگر منتشر می‌شوند؛ کلید secret/service-role برای آنها ممنوع است.
